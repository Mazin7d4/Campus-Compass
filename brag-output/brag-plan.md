# Brag Plan: Campus Compass

## What is this app?
Campus Compass is a campus navigation app covering all 23 California State University campuses — search a building by name or abbreviation, then hand off to Apple or Google Maps for turn-by-turn directions.

## The angle
Low-vision students shouldn't need a readable map to get to class. Campus Compass replaces "find it on the campus map" with searchable text, large controls, screen-reader labels, and native map handoff — on every CSU campus.

## Hook (first 2-3 seconds)
Giant line: "Campus maps assume you can see them." Soft, serious. No joke energy.

## Key moments (the middle)
- All 23 CSU campuses appear as a clean campus-chip grid / count-up to 23.
- Real product flow: search field → type a building abbreviation → large building rows with mono badges (as in the app).
- Big Navigate button + "Opens Apple Maps or Google Maps" — the step that hands off to VoiceOver/TalkBack-ready native navigation.

## Outro / punchline
Campus Compass.
Every CSU campus. Built to be found.

## User flow worth showing
Home search/campus pick → building search by name/abbreviation → building detail with large Navigate CTA that opens Apple/Google Maps.

## Tone
- Preset: polished (with app-store feature clarity)
- Creative direction: accessibility product film for CSU low-vision navigation
- Interpretation: Confident restraint, long holds on readable type, feature-forward without corporate SaaS fluff. Earnest, not cute.
