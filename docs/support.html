Campus Compass Support

Campus Compass helps users find campus buildings and open directions in a maps app.

Campus Compass is an independent campus navigation guide. It is not affiliated with, endorsed by, or sponsored by California State University or any CSU campus.

Getting Help

For app support, bug reports, or correction requests, open a support request at github.com/Mazin7d4/Campus-Compass/issues.

Before Contacting Support

  • Make sure you are using the latest version of Campus Compass.
  • If the app icon or layout looks stale after an update, delete and reinstall the app.
  • If a building is missing or incorrect, include the campus name and building name.
